# Setup & Build Instructions

## Prerequisites

- **Node.js** v18+
- **Windows** (for packaging — the installer targets Windows x64)
- A `.env` file (copy `.env.example` and fill in values)

---

## Development

```bash
# 1. Install dependencies
npm install

# 2. Generate Prisma client
npm run db:generate

# 3. Push schema to SQLite (creates prisma/pos.db)
npm run db:push

# 4. Seed initial data (admin user, categories etc.)
npm run db:seed

# 5. Start dev servers (Vite on :5173, Express on :3000, Electron window)
npm run dev
```

> Tip: set `ELECTRON_DEBUG=1` in your `.env` to open DevTools automatically.

---

## Building the Windows installer

```bash
# One command does everything:
npm run package
```

This runs in order:
1. `vite build` — compiles the React frontend into `client/dist/`
2. `scripts/beforeBuild.js` — runs `prisma generate` and creates a seed `prisma/pos.db`
3. `electron-builder` — packages everything into `dist-electron/AI POS System Setup.exe`

### First-time setup after installing

When a user runs the installer and opens the app for the first time:
- The main process copies `prisma/pos.db` from the app bundle into `%APPDATA%/AI POS System/data/pos.db`
- A random JWT secret is generated and stored in `%APPDATA%/AI POS System/jwt-secret.txt`
- The Express server starts on port 3000 and the UI loads automatically

### App icon

Place a 256×256 `icon.ico` file at `electron/icon.ico` before packaging.
If no icon is found, electron-builder uses its default Electron icon.

## Environment variables

Copy `.env.example` to `.env` and fill in:

```
DATABASE_URL=file:./prisma/pos.db   # dev only — overridden at runtime in packaged app
JWT_SECRET=change-this
NODE_ENV=development
PORT=3000
APP_URL=http://localhost:3000

# AI insight generation (optional — falls back to cached narrative when offline)
ANTHROPIC_API_KEY=sk-ant-...
AI_INSIGHT_MAX_AGE_HOURS=12
```

## Troubleshooting packaged app

| Symptom | Cause | Fix |
|---------|-------|-----|
| App installs but window never opens | Server failed to start | Check `%APPDATA%/AI POS System/electron.log` |
| Blank white screen | `client/dist` missing from bundle | Run `npm run build` then `npm run package` |
| `PrismaClientInitializationError` | Prisma engines not unpacked | Confirm `asarUnpack` includes `node_modules/.prisma/**` |
| `Missing required environment variables` | `.env` not loaded | Ensure `.env` exists in app root for dev; packaged app auto-generates secrets |
| App opens then immediately closes | Migration failed | Check log; run `npm run db:generate` before packaging |

## Project structure

```
ai-pos-system/
├── electron/
│   ├── main.js           # Electron main process — starts server, creates window
│   └── icon.ico          # App icon (add before packaging)
├── server/               # Express API (runs as Node child process in packaged app)
├── client/               # React frontend (Vite)
│   └── dist/             # Built output — generated by npm run build
├── prisma/
│   ├── schema.prisma
│   ├── migrations/
│   └── pos.db            # Seed DB — generated by scripts/beforeBuild.js
├── ai/                   # ONNX models, calendar data
├── scripts/
│   └── beforeBuild.js    # electron-builder hook
└── package.json
```
